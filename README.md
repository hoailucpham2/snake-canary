# 🐍 Snake Canary

A simple classic Snake game for Android, built with Kotlin and custom Canvas drawing.

## Features

- Classic snake gameplay with swipe controls
- Smooth rendering using Android Canvas
- Dark theme UI
- Build info page for QA traceability

## Build

```bash
./gradlew assembleDebug
```

## Requirements

- Android SDK 34
- JDK 8+
- Gradle 8.2+
